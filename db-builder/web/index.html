Databases

    No database open

    Choose a database on the left, open a .sqlite file of the root, or make a new one. Then add tables, exports and folders of recordings to it; Medorama connects the database it makes.

    Tables (CSV, Excel, OpenDocument, Parquet), known exports (GE MUSE, a site's declared format) and CLIF folders, each a source. Preview reads them and says what would be added, writing nothing; Add adds them, all or nothing. The database's rules (Rules) apply to both.

    Inputs

      Options

      A folder of recordings and its subfolders (WFDB records, EDF and BDF files, files an installed adapter reads), one source; each recording's patient from a patients table (its file and patient), or from a pattern of the files' names.

      Rewrite rules, kept beside the database () and applied to every add from this page: files' paths ([[path]]: a prefix or a regular expression) and identifiers ([patient_id], [mrn], [encounter_id]: replacements and case). Checked before they are saved.

      Rewrite the paths the database lists

      For data moved or mounted elsewhere since it was built: its recordings', entries' files' and sources' paths rewritten by the saved [[path]] rules. The files are not read again; Check then lists any still missing.

      What a reader cannot rely on: patient IDs without an issuer, MRNs without an authority, identifiers given to two persons, keys naming nothing, entries whose person is not their visit's, missing files. Named by key, never by name or MRN.

      Each file added (each table of a CLIF folder, each folder of recordings) is a source. Removing one takes out its entries, recordings and extras, and the persons and visits nothing else names.
