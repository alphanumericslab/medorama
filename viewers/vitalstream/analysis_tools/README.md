# Analysis tools

This folder holds analysis code for physiological recordings that is not part of the
[VitalStream](../README.md) viewers' packages. It is for researchers who want to process the
recordings they view. The scripts read data from, and write results to, the viewer's
`sample_data/` folder, which git never pushes.

| Folder | Contents |
|---|---|
| [`matlab/`](matlab/README.md) | MATLAB scripts that read the records of a WFDB collection. |
